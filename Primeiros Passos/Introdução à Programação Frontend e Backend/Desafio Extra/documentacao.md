## 2. Descrição das Etapas de Desenvolvimento
O desenvolvimento seguiu rigorosamente os requisitos técnicos e estruturais solicitados no edital do desafio extra:

1. **Identidade Visual e Tipografia:** Foi definida uma paleta de cores baseada no rosa predominante da marca real da clínica. Foram utilizadas fontes externas do Google Fonts ("Fredoka" para títulos e "Poppins" para textos) para garantir um aspecto moderno e acolhedor. 
2. **Estruturação Semântica (HTML):** A página foi organizada utilizando as tags semânticas do HTML5 para garantir acessibilidade e boa estrutura de SEO. 
3. **Seção de Destaque (Hero):** Foi utilizado o modelo de layout em duas colunas através de Flexbox, organizando o texto à esquerda e a imagem da capa à direita. O layout garante que a imagem não sobreponha o texto, mantendo a legibilidade em diferentes dispositivos.
4. **Seção Sobre:** Esta seção descreve a história e missão da clínica, utilizando Flexbox para o alinhamento de informações e exibição de indicadores de experiência, como o número de pets atendidos. 
5. **Seção de Serviços:** Foram criados cards visuais para os serviços (Clínica, Banho & Tosa e Pet Shop), aplicando a propriedade CSS `aspect-ratio` para garantir a proporção uniforme dos elementos. 
6. **Seção de Contato e Interatividade:** Foi implementado um formulário funcional na camada de front-end com validação básica via JavaScript. O script valida o preenchimento dos campos obrigatórios e o formato do e-mail antes do envio.
7. **Responsividade:** O projeto foi otimizado através de Media Queries para garantir que a página seja totalmente funcional e organizada tanto em computadores quanto em dispositivos móveis.

## 3. Guia Rápido de Execução
Para visualizar o projeto localmente, siga estes passos:

1.  Extraia todos os arquivos do pacote compactado (.zip ou .rar) em uma pasta local.
2.  Certifique-se de que a estrutura de pastas contém os arquivos `index.html`, `style.css`, `script.js` e a pasta de imagens `img/`.
3.  Abra o arquivo `index.html` em qualquer navegador web moderno (Google Chrome, Firefox ou Edge).
4.  Para testar a interatividade, navegue pelo menu superior ou preencha o formulário de contato ao final da página para verificar a validação de campos.
